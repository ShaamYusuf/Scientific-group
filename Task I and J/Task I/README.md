Problem Statement

A financial application requires the computation of an interest rate that makes the Net Present Value (NPV) of an investment equal to zero.
The investment involves an initial cash outflow followed by a series of annual cash inflows. The objective is to determine the Internal Rate of Return (IRR) using numerical methods.

The IRR is the discount rate at which the total present value of future cash inflows equals the initial investment.

Mathematically, the NPV is defined as:

[
NPV(r)=\sum_{t=0}^{n}\frac{CF_t}{(1+r)^t}
]

Where:

(r) = discount rate.

(CF_t) = cash flow at time (t).

(t) = time period.

(n) = total number of periods.

The objective is to find the value of (r) such that:

[
NPV(r)=0
]

 Solution Approach

The problem is solved using two numerical methods:

 Newton-Raphson Method

The Newton-Raphson method is used to estimate the IRR by applying the derivative of the NPV function.

The iteration formula is:

[
r_{n+1}=r_n-\frac{NPV(r_n)}{NPV'(r_n)}
]

An initial guess of 0.10 (10%) is used.

2.2 Secant Method

The Secant Method is applied to estimate the IRR using two initial guesses without requiring the derivative of the NPV function.

The initial guesses used are:
First guess: 0.05 (5%).
Second guess: 0.20 (20%).
Both methods use a tolerance of (10^{-12}).

Assumptions

The following assumptions are considered when solving the problem:
The initial investment occurs at the beginning of the project (Year 0).
All cash inflows occur at the end of each year.
Cash flows are assumed to be known and constant.
The discount rate remains constant throughout the investment period.
The investment has one meaningful IRR for the given cash-flow pattern.
The numerical methods converge to the same solution within the specified tolerance.
The cash flows are measured in the same currency.
