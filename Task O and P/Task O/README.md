# BIT 2118 — Scientific Computing

**Institution:** Mount Kenya University (MKU)

## Task O: Numerical Integration

This project demonstrates numerical integration using Python to estimate accumulated quantities from sampled data.

### Programs

- `code/Task_16_numerical_integration.py` — Estimates electrical energy from smart-meter readings using the trapezoidal and Simpson's rules.
- `code/irrigation_water_volume.py` — Estimates water delivered by an irrigation pump using sampled flow-rate measurements.

### Requirements

- Python 3
- NumPy
- SciPy

Install the required libraries:

```bash
python -m pip install numpy scipy
```

### Running the programs

```bash
python code/Task_16_numerical_integration.py
python code/irrigation_water_volume.py
```

### Learning objectives

- Understand numerical integration.
- Compare the trapezoidal and Simpson's rules.
- Investigate how changing input data affects the results.
- Apply numerical integration to a related real-world problem.

### Results and documentation

The accompanying Task O report documents the assumptions, input data, outputs, and interpretation. Results should be verified by running the programs.
